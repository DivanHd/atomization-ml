# Atomization Energy ML

Прогнозирование энергии атомизации молекул методами машинного обучения на основе датасета **RoboBohr** (~16 000 молекул, 1275 молекулярных дескрипторов).

Проект разработан в рамках курсовой работы по дисциплине «Машинное обучение для решения задач здравоохранения» (РТУ МИРЭА, направление 09.03.01 «Информатика и вычислительная техника»).

## Описание проекта

Пайплайн реализует полный цикл ML-эксперимента:
- загрузку и первичный анализ данных из CSV-файла;
- удаление выбросов методом межквартильного размаха (IQR);
- разделение выборки на обучающую (80%) и тестовую (20%) части;
- стандартизацию признаков (`StandardScaler`);
- обучение одной из 7 моделей регрессии: `LinearRegression`, `Ridge`, `Lasso`, `RandomForest`, `GradientBoosting`, `SVR`, `KNN`;
- вычисление метрик качества: MAE, RMSE, R²;
- автоматическое сохранение модели, масштабировщика и метрик в каталог результатов с временной меткой.

Лучшая модель в рамках исследования — **Gradient Boosting** (R² = 0.9992 на тестовой выборке).

## Требования к окружению

- **ОС:** Linux / macOS / Windows (с Docker Desktop)
- **Docker** версии 24.0+ и **Docker Compose** v2
- **Git** (для клонирования репозитория)
- Свободное место на диске: ~2 ГБ (для Docker-образа)

## Установка зависимостей

Проект полностью контейнеризован, поэтому локальная установка Python и библиотек **не требуется**. Все зависимости (`numpy`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`, `scipy`, `joblib`) описаны в файле `pyproject.toml` и устанавливаются внутри Docker-образа с помощью менеджера `uv`.

Сборка образа выполняется одной командой:

```bash
docker compose build
```bash
docker compose up
